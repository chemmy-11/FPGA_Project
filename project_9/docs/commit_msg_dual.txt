project_9: 双笼真光链路版(A<->B) —— 数据渡光两次, 首版 WNS=+1.008ns

光口映射(官方55例程XDC注释+GT LOC 双证据): A=Y11=X1Y11, B=Y9=X1Y9, C=Y10, D=Y8.
架构: B 通道克隆 Aurora IP aurora_64b66b_1(X1Y9) 作'远端镜像',
  support_ext(A) 引出 refclk+QPLL 四件套; support_shared(B) 无 GT_COMMON(一 quad 一 common),
  B.RX -> FWFT FIFO 512x80b(tkeep/tlast 折叠进载荷) -> B.TX 弹性回显.
  数据渡光两次: A.TX ->光-> B.RX ->FIFO-> B.TX ->光-> A.RX -> 解包 -> 泵B -> PC.
  A 侧数据通路(泵/打包/解包)与 prj8 判据全过版零改动; link_ok=双 channel_up 门控.
踩坑记: (1)残留 vivado 进程锁 runs 目录致 create_project -force 失败;
  (2)fifo_generator 无 Write_Depth_Flag/Full_Flag_Reset_Value 参数名;
  (3)核的 gt_pll_lock 是状态输出口, 外部不可 assign 驱动(MDRV-1),
    外部锁定状态只走 gt_qplllock_quad1_in.
XDC: B 笼控制脚按官方 55 号: rs0=AH11 rs1=AG11 tx_disable=AH12.
