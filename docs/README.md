## 文档命名规范（v1 · 2026-09-19）

```
[阶段]_prj标识_概要_YYYY-MM-DD.md
```

四段以下划线连接，**禁空格**；各段约定：

| 段 | 取值 | 说明 |
|---|---|---|
| 阶段 | `阶段一` / `阶段二前置` / `阶段二之三`…`阶段二之八` / `阶段三` | 所属开发阶段（阶段号沿用任务分工与路线图口径） |
| | `前置` | 无阶段归属的认知准备类（如查原理图入门） |
| | `参考` | 无阶段归属的技术参考（引脚表、外部诊断等） |
| | `里程碑` | 里程碑总结（M1 进度总结等） |
| prj标识 | `prj1`…`prj9` | 对应 `D:\FPGA\project_N` |
| | `ibert` / `aurora-ex` | 非 prj 编号的例程工程（ibert_ultrascale_gth_0 / aurora_64b66b_loop_ex） |
| | `cross` | 跨工程通用文档 |
| 概要 | ≤15 字短词 | 中文或英文，去掉空格 |
| 日期 | `YYYY-MM-DD` | 定稿日期：取 frontmatter `created`；原文件名已含日期的沿用 |

豁免：目录级索引 `README.md`、vault 会话入口 `agent.md`（`AGENTS.md` 的镜像摘要，冲突以 AGENTS.md 为准）与非 Markdown 数据文件（如 `KU引脚表.xlsx`）不受此规范约束。
示例：`阶段二之八_prj8_数据级桥上板验证单_2026-09-10.md`。
