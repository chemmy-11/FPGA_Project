## 一、跑之前（1 分钟）

**前提**：板子**刚烧过位流**。位流断电即失；**上一次实验已把板子打到冻结**，所以每次复现前都要先重烧一次。

```powershell
cd D:\FPGA\prj\project_9
D:\Xilinx\Vivado\2023.1\bin\vivado.bat -mode batch -notrace -source scripts\program_board.tcl
ping 192.168.1.10 -n 3
```

**判据**：脚本打印 `PROGRAM_OK` + `调试核数量` + 各核"时钟在跑"；ping **3/3 回包**。
> ping 不通就先别往下走——先重烧；还不行再找我。

## 六、跑不出上面数字时怎么判断

| 现象 | 含义 | 怎么办 |
|---|---|---|
| ping 3/3，但速率只有几 Mbps | 节拍参数没生效（多半是命令被截断） | 重贴第二节整段命令 |
| 速率 ≈400 Mbps，但收到 7000 片 | 这次**没触发冻结**（属于"有效达标轮"） | **照样截屏**，这是有价值的一次对照 |
| 收到片数远小于 3000 | 发送前板子状态不对 | 回第一节重烧再来 |
| 屏幕乱码 | 控制台编码问题 | `chcp 65001` 后重跑，或直接看我给的日志文件 |
| 板子一直 ping 不通且重烧也不行 | 需要我看现场 | 停手，把 `program_board.tcl` 整段输出发我 |
