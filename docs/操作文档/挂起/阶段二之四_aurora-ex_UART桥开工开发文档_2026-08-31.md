## 1. 任务与判据（一句话）

PC 串口发数据 → 自写 UART/帧适配 → Aurora（内部 PMA 环回）→ 原样收回 → **1MB 逐字节比对 PASS**（115200 与 921600 双档）= 上下位机通信 + SFP 传输双验证。

## 2. 工程与设计分解

- 工程：`D:\FPGA\project_5`（uart_aurora_bridge，part 非 CIV，全英文路径）
- 复用：Aurora IP 参数 = 阶段二之三定版（duplex/X1Y11/内部环回 3'b010/framing）——迁移方式见 U3
- 新 RTL（约 400 行）：

| 模块 | 职责 | 关键点 |
|------|------|--------|
| `uart_rx.v` | 16× 过采样采样 RX，输出字节+valid | 起始位同步、半 bit 采样点、帧错误检测 |
| `uart_tx.v` | 移位输出，busy 握手 | 同分频器 |
| `uart_frame.v` | 帧适配：RX 字节流 → `[len8][payload×len]` 块 → Aurora AXIS(tlast)；反方向拆块 | len=255 续块；防跨帧粘连 |
| `bridge_top.v` | 顶层：时钟（ui_clk 单域！）+ 复用 ddr4 式批量构建 + ILA×5 + LED T22/T23 | 单时钟域设计，UART 用 ui_clk 分频，消除 CDC（关键简化） |

- 关键简化决策：**UART 逻辑跑在 Aurora ui_clk（151.5MHz）单时钟域**——UART 与 Aurora 之间零 CDC；FT2232H 是异步源，由 UART RX 过采样天然吸收。
- XDC：AE33/AF34（UART）+ AK17/AK16（sys_clk）+ AC34（reset）+ T22/T23（LED），IOSTANDARD 沿用各卡已实证值。

## 4. 风险与预案

- R1 帧适配对齐 bug（tlast/len 错位）→ **subagent 独立评审**把关后再编译；
- R2 构建迭代失败 → MIG 四轮排障经验全套复用（幂等脚本+逐错定位）；
- R3 Aurora 配置迁移不干净 → U3 兜底；
- R4 921600 不稳 → 判据只认 115200，921600 记为"加分观测"。
