## 1. 手册 → 本板差异对照（唯二要换的地方）

| 手册说 | 本板实际做 |
|--------|-----------|
| Quad X0Y2 全 4 通道 | **QUAD_226 = X1Y2**；只勾 X1Y11（SFPA）1 通道 |
| 光模块控制引脚（底板版球号） | **版本 A** 12 行（§2 XDC 已备好，直接粘） |

其余（预设、编码、位宽、时钟源、K28.5、时钟纠正）**与手册一致**，照走。

## 2. 可粘贴 XDC（例程生成后追加到 imports 的 exdes xdc 末尾）

```tcl
## ===== sys_clk 100MHz diff (freerun clock) =====
set_property -dict {PACKAGE_PIN AK17 IOSTANDARD DIFF_HSTL_I_12} [get_ports sys_clk_p]
set_property -dict {PACKAGE_PIN AK16 IOSTANDARD DIFF_HSTL_I_12} [get_ports sys_clk_n]
create_clock -period 10.000 -name sys_clk [get_ports sys_clk_p]

## ===== FMC_4SFP control signals, VERSION A =====
set_property -dict {PACKAGE_PIN H26  IOSTANDARD LVCMOS33} [get_ports {sfp_tx_disable[0]}]
set_property -dict {PACKAGE_PIN AH12 IOSTANDARD LVCMOS33} [get_ports {sfp_tx_disable[1]}]
set_property -dict {PACKAGE_PIN J25  IOSTANDARD LVCMOS33} [get_ports {sfp_tx_disable[2]}]
set_property -dict {PACKAGE_PIN AF12 IOSTANDARD LVCMOS33} [get_ports {sfp_tx_disable[3]}]
set_property -dict {PACKAGE_PIN G27  IOSTANDARD LVCMOS33} [get_ports {sfp_rs0[0]}]
set_property -dict {PACKAGE_PIN AH11 IOSTANDARD LVCMOS33} [get_ports {sfp_rs0[1]}]
set_property -dict {PACKAGE_PIN M26  IOSTANDARD LVCMOS33} [get_ports {sfp_rs0[2]}]
set_property -dict {PACKAGE_PIN AF13 IOSTANDARD LVCMOS33} [get_ports {sfp_rs0[3]}]
set_property -dict {PACKAGE_PIN H27  IOSTANDARD LVCMOS33} [get_ports {sfp_rs1[0]}]
set_property -dict {PACKAGE_PIN AG11 IOSTANDARD LVCMOS33} [get_ports {sfp_rs1[1]}]
set_property -dict {PACKAGE_PIN M25  IOSTANDARD LVCMOS33} [get_ports {sfp_rs1[2]}]
set_property -dict {PACKAGE_PIN AE13 IOSTANDARD LVCMOS33} [get_ports {sfp_rs1[3]}]
```

> 例程自带的 xdc 里 refclk 引脚约束**生成时自动带**——生成后 30 秒自检：打开 imports 下的 xdc，确认 refclk 落在 **T6/T5**（出现 V6/V5 = Quad/时钟选错，回 IP 改）。端口名若与例程顶层不一致，以顶层实际端口名为准改 XDC（不要反向改语义）。

## 3. 流程骨架（8 步，细节看手册）

1. 新建工程：`D:\FPGA\project_3`，工程名建议 **gth_8b10b**（part=`xcku060-ffva1156-2-i` 非 CIV）；
2. IP Catalog → **Transceivers Wizard（UltraScale GTH）**，按 §0 表逐页配置 → Generate；
3. 右键 IP → **Open IP Example Design**（选新目录，别覆盖旧工程）；
4. 改例程顶层 3 处（手册 §57.4/笔记 §4.3）：① 注释 reset helper 外部端口与 link status 端口；② `sys_clk_p/n` 差分输入 → IBUFGDS → 接 `hb_gtwiz_reset_clk_freerun_in`；③ 加 `sfp_tx_disable/rs0/rs1` 输出并 assign（0/1/1）；
5. **补 stimulus/checking/prbs_any 模块**（手册源码包里有，XAPP884）——例程不一定自带，缺了从手册源码拷 .v 进 imports；
6. 追加 §2 XDC（纯 ASCII，粘到 imports 的 exdes xdc 末尾）；
7. 综合 → 实现 → 位流（有 IBERT 经验，20~40 分钟）；
8. 上板：断电接光纤 **SFPA 单口自环**（TX→RX）→ 上电 → HW Manager 烧 bit → Open Hardware Manager 里的 ILA。

## 5. 坑位速查（前车之鉴）

| 症状 | 先查什么 |
|------|---------|
| 综合 syntax error near 'output' | 顶层端口列表**逗号**（IBERT 踩过：原最后端口行尾补逗号再接自己的端口） |
| get_ports 报 No open design | XDC 是文件不是 Tcl Console 命令 |
| PLL 不锁 / GT 无输出 | 向导里时钟源必须 **MGTREFCLK1**；XDC refclk 必须是 T6/T5 |
| ILA 里 rxdata 死值 | 光纤没自环好 / tx_disable 没拉低（XDC 版本 A 是否生效） |
| prbs 错误恒 1 | 检查器 CHK_MODE/取反接法；先确认 comma 对齐逻辑工作（txctrl2=0x0F 发 K 码阶段） |
| 顶层被覆盖 | 例程重新生成会重置 imports——补丁永远做在**新生成的**文件里 |
| 找不到手册的 Quad X0Y2 | 手册截图是旧版 Vivado 的 GT 列编号；2023.1 里同一物理 Quad 叫 **X1Y2**（右列，Bank 226）。**认 Location details 的 Bank 226 + Data pins（SFPA=R3/R4），不认 X 编号** |
| Master channel 指向莫名的 X0Y14 | 说明通道勾在了**左列 Quad X0Y3**（错，非 Bank 226）→ Disable All Channels 全清后重勾右列 X1Y2 里的 X1Y11 |
| 中文注释乱码/报错 | Vivado 编辑器里源文件注释只用 ASCII |
