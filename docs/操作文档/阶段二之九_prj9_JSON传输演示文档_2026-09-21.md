# 演示文档：会话 JSON 传输质量三档演示（prj9）

## 〇、演示逻辑（先想清楚要讲什么）

三档递进，各回答一个问题：

| 档 | 命令核心 | 预期结果 | 回答的问题 |
|---|---|---|---|
| **① 质量档** | 100KB @1ms | **100% 到达 + SHA256 全文一致** | “数据一个字节都不会错吗？” |
| **② 性能档** | 全量 10MB @0.1ms | **99.84% + 19.3 Mbps，4.25 秒渡完** | “能跑多快？” |
| **③ 容量档**（讲数据不现场跑） | --parallel 4 | 送 70 Mbps 只回 22.9 | “极限在哪？瓶颈是什么？” |

负载均为**本会话真实 JSON 记录**（10.3MB / 2808 行）——未来 agent 间传输的就是这类数据。

## 三、② 性能档（约 7 秒）

```powershell
& $py scripts\json_storm.py testdata\session_full.jsonl --chunk 1360 --gap-ms 0.1
```

**判读**：收到 99.8%± · 损坏 0 · **发送阶段速率 ~19.3 Mbps** · 发送用时 ~4.3s · RTT avg ~0.25ms

注：19.3 Mbps 是 **PC 端 python 单流发包的天花板**（sleep 精度+每帧一次系统调用+GIL），
不是链路的——10G Aurora 余量还有 500 倍。这句话演示时要点明。

## 四、③ 容量档（用数据讲，不建议现场跑）

已归档的实测（2026-09-21，`testdata/storm_p4.log`）：

```
4 进程并行（各持独立端口，合计送出 ~70 Mbps）：
  收到 33.77% · 回程聚合 22.9 Mbps · 损坏 0
结论: 系统端到端串行化容量 ≈ 23 Mbps（每帧独占全路径 ~230µs，与 RTT 吻合）
瓶颈链: 全链 store-and-forward（帧泵×2 + pack×3 + B 回显）逐级整帧缓存
```

**为什么不当场跑**：过载冲击（大量帧冲突丢弃）会触发板端硬冻结（ping 全灭），需重烧恢复。
现场想跑也行，但必须紧接着执行第一节的重烧命令，并预留 1 分钟。

话术：“我们用 4 进程把到达率压到 34%，反向测出了系统的串行容量 23 Mbps——
瓶颈不在光链路（10G 余量充足），在交换结构的整帧存储转发流水线，
下一步的帧泵 v2 多帧队列就是冲它去的。”

## 五、判读口诀（通用）

- **丢失/损坏/逆序三个 0 + SHA 一致** = 完美（质量档的标准像）
- 性能档丢 ~0.2% 属 Aurora 渡纤段已知底噪（见评测报告），**损坏必须 0**
- RTT 亚毫秒即正常

## 六、故障预案

| 症状 | 处置 |
|---|---|
| 脚本/命令报板子不通 | 刚上电→重烧；T23 灭→查光纤与模块 |
| python 秒崩 UnicodeEncodeError | 忘了 `$env:PYTHONUTF1='1'`（正确变量名 PYTHONUTF8）|
| 收到 0 但 ping 通 | 1234 端口被残留进程占用，关旧窗口 |
| 任何档丢片异常放大 / ping 全灭 | 板端冻结（累计流量或过载触发）→ 重烧即恢复 |

## 八、附录：手动命令与参数释义（理解原理用）

```powershell
$env:PYTHONUTF8 = '1'                          # 必须：GBK 控制台打 ✓ 会崩
cd D:\FPGA\project_9
$py = 'C:\Users\***\AppData\Local\Python\pythoncore-3.14-64\python.exe'
& $py scripts\json_storm.py testdata\session_full.jsonl --limit-bytes 102400 --chunk 1360 --gap-ms 1.0
```

| 参数 | 意义 | 选用理由 |
|---|---|---|
| 文件参数 | 要传的文件 | 换任何文件可测（本次 = 会话记录快照）|
| `--limit-bytes N` | 只发前 N 字节 | 小量秒级反馈；去掉即全量 |
| `--chunk 1360` | 每片 1360B（+6B 帧头 = 1408B 帧）| 1408 < 1500 MTU，避免 IP 分片 |
| `--gap-ms X` | 发送间隔 | >0.5ms 人为限速；≤0.3ms 撞 PC 单流天花板 |
| `--parallel N` | 多进程并行（独立端口）| 容量探测用；过载会触发板端冻结 |
| `--out 路径` | 重组文件落盘 | SHA 比对物证 |
