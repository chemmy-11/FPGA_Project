## 1. 任务与判据（一句话）

PC 经 UDP 发实际数据 → 以太网栈解析回显 → **回显帧穿过 Aurora 64b/66b 编解码（GT 内环）** → 原样回 PC；PC 脚本逐字节比对 **P' == P = PASS**。

## 2. 工程与设计分解

**工程**：`D:\FPGA\project_8`（aurora_udp_bridge，part=`xcku060-ffva1156-2-i`）

### 2.1 复用（零改动）

| 模块 | 来源 | 说明 |
|---|---|---|
| 以太网栈 15 文件（eth_udp_loop/arp/icmp/udp/eth_ctrl） | 官方 39 例程（project_6 同源） | 协议解析与回显 |
| `gmii_to_rgmii`（rgmii_rx/rgmii_tx） | 官方 39 例程 | RGMII ↔ GMII |
| `async_fifo_2048x8b` IP | project_6 | 栈内回显缓冲 |
| `frame_fifo_pump.v` | project_7（自研） | 帧门控 CDC（8-bit） |
| `aurora_64b66b_0` IP | project_3 / aurora 例程 | 10G duplex X1Y11，64-bit UI |

### 2.2 新增 RTL

| 模块 | 职责 | 关键点 |
|---|---|---|
| `gmii_axis_pack.v` | GMII 8bit → AXIS 64bit 打包 | 8 字节凑一词；`tkeep` 标记有效字节；帧尾 `tlast` |
| `gmii_axis_unpack.v` | AXIS 64bit → GMII 8bit 解包 | 按 `tkeep` 掩码输出；帧尾拉低 dv |
| `aurora_udp_top.v` | 顶层集成 | Aurora 复位/时钟/PMA 处理 + 双泵 + LED + mark_debug |

### 2.3 时钟与复位（Aurora 侧，参考 08-31 实证）

| 信号 | 来源 | 说明 |
|---|---|---|
| `gt_refclk1_p/n` | T6/T5 @156.25MHz | MGTREFCLK1_226（定版） |
| `init_clk_p/n` | AK17/AK16 100MHz 差分 | Aurora init_clk（独立于恢复钟） |
| `user_clk_out` | Aurora 输出 ~151.5MHz | 时钟域 B |
| `sync_clk_out` | Aurora 输出 | 内部同步用 |
| 复位 | `system_reset_i \| !channel_up_i` | 链路未建立时复位数据通路（例程同款） |
| `pma_init` | 上电脉冲（128 级移位） | GT 复位时序（例程同款） |
| `loopback` | `3'b010` | 近端 PMA 串行内环（实证） |

## 3. 不确定点清单（按查证路径逐条消解）

| # | 不确定点 | 查证路径 | 兜底 |
|---|---|---|---|
| U1 | Aurora IP 迁移方式 | **试**：`import_ip` 导入 xci（project_7 已证 `read_ip` 会致生成物路径漂移） | 失败则脚本重建 + xci 参数逐项核对 |
| U2 | AXIS 字节序（`tdata[7:0]` 是否对应首字节） | **查例程**：`aurora_64b66b_0_example_ll_to_axi.v` 的字节映射 | ILA 抓单帧比对（发已知图案） |
| U3 | `tkeep` 位语义（每 bit ↔ 每字节？） | 同上 + PG046 | 先按 8bit=8 字节全有效实现，ILA 验证 |
| U4 | `tlast` 与帧边界（framing 模式） | 例程 `frame_gen`/`ll_to_axi` 用法 | 单帧收发 ILA 核对 |
| U5 | 帧泵位宽适配（现有 8-bit pump vs 64-bit AXIS） | **设计决策**：pump 保持 8-bit，打包/解包放在 pump 的域内 | 若时序紧张则改 64-bit pump |
| U6 | `s_axi_tx_tready` 反压处理 | 帧泵读出侧需响应 tready | 加 tready 门控（读侧暂停） |
| U7 | init_clk 是否需要 clk_wiz | **查 XDC**：例程直接收 `init_clk_p/n` 差分 | 如需单端则加 IBUFDS |
| U8 | Aurora IP 参数是否与 08-31 定版一致 | 对照 `project_3` 的 xci（10G/X1Y11/duplex/framing/64-bit/无 CRC） | 不符则 import 后核对修正 |

## 4. 风险与预案

| # | 风险 | 预案 |
|---|---|---|
| R1 | AXIS 打包边界错（tkeep/tlast 错位）→ 帧错乱 | ILA 抓首帧逐字节核对；必要时先用固定图案自测（不经 PC） |
| R2 | IP 迁移不干净（生成物路径漂移/参数不符） | `import_ip` + xci 双证终验（Aurora 实操单 §1 套路） |
| R3 | CDC 丢帧 | 帧泵已有 `wr_drop_cnt` 计数；人工节奏下不应发生 |
| R4 | 时序违例（125M ↔ 151.5M + 打包逻辑） | `-jobs 2` 迭代；参考 project_7 时序全绿经验 |
| R5 | ⚠️ 中文工作目录致 dbg_hub 子进程崩溃（project_7 实录） | **必须在纯 ASCII 工作目录运行 vivado**（`cd D:\FPGA\project_8`） |
