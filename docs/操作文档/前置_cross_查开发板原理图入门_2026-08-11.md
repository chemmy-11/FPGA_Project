# 如何查开发板原理图（新手入门）

> **为什么要查**：阶段二（SFP 收发）动手前必须确认两件事——① 板载 **MGTREFCLK 参考时钟**的频率与引脚（Aurora 10G 的前提，选错必挂）；② **SFP+ 光口**连到 FPGA 的哪个 GTH 通道。这些信息只有原理图里有。
>
> **原理图是什么**：就是开发板的电路图纸（通常是几百页的 PDF），记录"FPGA 的每个引脚连到了板上哪个器件"。新手不需要通读，按"信号名 → 找到它"来查即可。

---

## 0. 最快路径：先找厂家例程的 XDC，再查原理图

> ⚠️ **90% 的情况不用从零查**。开发板厂家（正点原子/米联客/ALINX 等）的资料包里，**例程工程自带 .xdc 约束文件**，里面可能已经写好了 GT 引脚约束（参考时钟、SFP 差分对）。

1. 下载开发板**资料包**（厂家官网/网盘，通常含：原理图 PDF、用户手册、例程源码、芯片手册）
2. 在例程里搜 `*.xdc`，打开看有没有这些关键词：`MGTREFCLK`、`MGTHTXP`、`MGTHRXP`、`SFP`、`gt_serial`
3. **有** → 直接抄引脚名，再用原理图**核对一遍**（防止例程与你的板子版本不同）
4. **没有** → 才需要按下面第 1~3 节从原理图查

> 你 M1 时用过的"官方 `KU_IO.xdc`"就是这种资源——里面已有系统时钟/复位/UART/LED 引脚，查 GT 引脚时先翻翻它和配套例程。

---

## 1. 打开原理图 PDF 的正确姿势

1. **用 PDF 阅读器**（浏览器/Adobe 都行），几百页不用从头看
2. **看左侧书签/目录**：厂家一般按模块分类——`时钟`、`电源`、`FPGA`、`DDR`、`SFP/光口`、`接口` 等，点目录直接跳
3. **Ctrl+F 全文搜索**是最核心技能：搜关键词，点结果跳转
4. **放大看网络名**：原理图上每根线旁有文字标签（网络名），如 `SFP1_TX_P`、`MGT_REFCLK_125M`

---

## 2. 查 MGTREFCLK 参考时钟（阶段二第 1 个待查项）

**目标**：确认①频率 ②FPGA 引脚号 ③属于哪个 Quad

**步骤**：

1. **先看时钟章节**：书签里找"时钟 / Clock / 晶振"页；或 Ctrl+F 搜 `REF`、`GT`、`MGT`、`CLK`
2. **找参考时钟源**：板上有个晶振或时钟芯片（如 SI5338、CDCM6208），它输出的一对差分线（网络名常带 `_P`/`_N`）通往 FPGA
   - 晶振丝印会标频率，如 `156.250`、`125.000`、`161.13`
   - 时钟芯片看原理图标注或配套手册的"频率配置表"
3. **跟到 FPGA 引脚**：沿差分线找到 FPGA 封装引脚号（BALL 号），如 `MGTREFCLK0_125`、`AL17` 这类名字
   - 关键特征：**MGTREFCLK 引脚只能接参考时钟**，普通时钟引脚（如 `AK17` 那个 100MHz）不能当参考时钟用——两者在原理图上长得不一样（MGTREFCLK 走专用通路）
4. **确认 Quad**：引脚名里常带 Quad 号（如 `MGTREFCLK0_125` 中的 `125` 就是 Quad 125），或查用户手册"GTH 资源分配表"
5. **与 Aurora IP 配置对照**：打开 Aurora IP 定制界面，Reference Clock 下拉列表会列出该线速率支持的频率——**板载频率必须在列表里**，否则要么换频率组合，要么调整线速率

> ⚠️ **常见误区**：板卡上最常见的系统时钟是 100MHz/125MHz，但那是给逻辑用的；**GTH 参考时钟是独立的一路**，必须从 MGTREFCLK 专用引脚进。查的时候别把两个混了。

---

## 3. 查 SFP+ 光口（阶段二第 2 个待查项）

**目标**：确认①几个光口 ②差分对连到哪个 GTH 通道 ③控制信号

**步骤**：

1. Ctrl+F 搜 `SFP`（或 `QSFP`、`光模块`、`CAGE`）
2. 找到 **SFP+ 连接器**（板上那个金属笼的图纸符号），看它的引脚：
   - **高速差分对**：`TX_P/TX_N`、`RX_P/RX_N`（发/收各一对）→ 跟着线找到 FPGA 的 **MGTHTXP/MGTHRXP** 引脚（网络名如 `MGTHTXP_125_3`，125=Quad，3=通道号）
   - 记下：这个口属于 **哪个 Quad 的哪个通道**（约束和 IP 配置要用）
3. **控制信号**（同一页附近）：
   - `TX_DISABLE`：关断发光，**低电平才发光**——要拉低/控制
   - `LOS`：信号丢失检测（收不到光会拉高）
   - `MOD_DEF0/SCL/SDA`：模块管理 I2C（可不管）
   - 看这些信号是直连 FPGA 普通 IO 还是接固定电平
4. **数清楚几个口**：一个口 → 用单根光纤 TX-RX 外部环回；两个口 → 可用 DAC 铜缆或两根光纤对插（决定你阶段二用哪种环回方式）

---

## 4. 常见网络名速查（看到就能认）

| 网络名特征 | 含义 |
|-----------|------|
| `MGTREFCLK0_125` / `MGTREFCLK1_126` | GTH 参考时钟（125/126 = Quad 号） |
| `MGTHTXP_125_0` / `MGTHRXN_125_0` | GTH 通道 0 的发送/接收差分对 |
| `SFP1_TX_P/N`、`SFP2_RX_P/N` | SFP 口 1/2 的收发差分信号 |
| `GT_REFCLK_156M25` | 带频率的参考时钟网络名 |
| `TX_DISABLE`、`LOS`、`MOD_DEF` | SFP 控制信号 |
| 后缀 `_P`/`_N` | 差分对正/负（**别接反**） |

---

## 5. 查完填这张表（填好就能开工）

```
参考时钟：
- 频率：____ MHz
- FPGA 引脚：________（MGTREFCLKx_Quad）
- 属于 Quad：____

SFP+ 光口：
- 数量：____ 个
- 口 1：TX→MGTHTXP_Quad_Ch / RX→MGTHRXP_Quad_Ch
- 口 2：____
- TX_DISABLE 接：____（FPGA IO 还是固定电平）
- LOS 接：____

环回方式：□ 单口光纤环回  □ 双口 DAC/光纤对插
```

填完对照 [[操作文档/阶段二_SFP收发与Aurora64b66b]] 第 3 节配置 Aurora IP。

---

## 6. 常见坑

- ❌ 把系统时钟（100MHz 那个）当 GT 参考时钟 → 必须 MGTREFCLK 专用引脚
- ❌ 差分对 P/N 接反 → 链路起不来，约束里 `_P`/`_N` 一一对应
- ❌ 参考频率不在 Aurora IP 支持列表 → 先查板子频率再配 IP，别先配 IP
- ❌ 例程 XDC 直接抄不核对 → 板子版本不同引脚可能不一样，抄完必须对照原理图验一遍
- ❌ 找不到 SFP 页 → 搜 `SFP` 没结果就试 `光模块`、`MGT`、`GTH`、`CAGE`
