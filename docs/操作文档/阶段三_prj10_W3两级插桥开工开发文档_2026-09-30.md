# prj10 W3 · 第一级插桥 + 换真 MIG 开工开发文档

> **定位**：执行实施单 v1.0 的 **W3**（以太网 → 内存写 → 内存读 → pack → Aurora，只插第一级；判据 **J2/J6**）。W3 的前置 = [[操作文档/阶段三_prj10_W3前置清单_2026-09-29]] 四项硬阻断（B1–B4）——**Q1–Q5 已定案（09-30）后全部解锁为可执行**，本单把它们排进双轨计划。
> **双轨原则**（延续 W2 的"可开工部分"方法论）：**轨 A（AI 离线，无板）**与**轨 B（用户上板，物理）**并行；红线不变——上板/烧录/插纤归用户，AI 只写操作清单与判读表；**本轮成文时未动任何 RTL、未建工程**。
> **工期预估**：轨 A 约 1.5–2 天（B1 1–2h / B3 数小时 / B3 半天内 / 集成+时序 1 天）；轨 B 每场次用户操作 0.5–1h + 判读；**合计 2–3 天**（与实施单 §8.1 W3 行一致）。

## 二、轨 A · AI 离线四步（无板，可立即开工）

### A1 = B1：补 12 个 AXI4 端口（1–2 h）

- **做法**：`axi4_master_bridge.v` 端口清单补齐（或包一层薄 wrapper，二选一，**优先直接加端口**——wrapper 会多一层层次妨碍 ILA 信号名）。
- **取值**（契约全表见前置清单 §五，此处只列补齐项）：

| 信号 | 位宽 | 取值 | 依据 |
|---|---|---|---|
| `awid` / `arid` | 4 | **必须给合法值**（建议 4'h0；MIG `r_channel.sv` 把 ID 搬进读事务缓冲再驱动 `rid`） | 前置清单 B1 |
| `bid` / `rid` | 4 | 输入可悬空（不比对 ID），**端口必须在** | 同上 |
| `awlock`/`arlock` | 1 | 常 0 | 可常量 |
| `awcache`/`arcache` | 4 | 常 0（Normal Non-cacheable）；**注**：若 MIG 校验拒绝再按 PG150 的 cache 属性要求调，先跑 A5 综合看 CW | 可常量 |
| `awprot`/`arprot` | 3 | 常 0 | 可常量 |
| `awqos`/`arqos` | 4 | 常 0 | 可常量 |

- **验收**：顶层 `synth_design` **0 CRITICAL WARNING**（对照修复前的 6 条 `[Synth 8-6858]` 基线）；`run_sim.bat` 回归仍 PASS（替身模型加相同端口，默认延迟不变）。

### A2 = B3-α：可变延迟 AXI 从机模型（数小时）

- **做法**：`sim/axi4_ram_model.v` 参数化 `LAT_W` / `LAT_R`（写响应延迟 / 读首拍延迟，默认 2/9 = 现替身行为，可配 0–500 拍）；监视器照旧。
- **跑法**：T1–T6 全判据在 `LAT_W/LR ∈ {(2,9), (50,50), (200,200), (500,500)}` 四档重跑。
- **产出**：① 判据表（各档全过/首败档）；② 用结果验证回归模型 `T_w = L + 3·ceil(L/64) + 4 + Lw`（误差应 <1%）；③ **首败档即"不流水时的延迟上限"**——与 `Lw+Lr > 636 拍破坏节拍`（实施单 §9.3）互为印证。
- **注意**：若某档判据失败（如 R 通道因长延迟死锁），那是**桥的流水能力缺陷被模型暴露**，按 bring-up 方法论（先单帧追迹再批量）定位——这正是 B3 存在的意义。

### A3 = B4：尾拍 WSTRB 专项（半天内，在 A2 模型上）

- **背景**：MIG 配 `AxiNarrowBurst=false`，桥按 64B/beat 发突发，末拍不满（1466 B → 23 拍，末拍 58 B 有效）。T1 虽已含 26/33/1000/1466 B 帧且逐字节一致，但那是**替身模型立即应答**的口径——真 MIG 对尾拍部分 WSTRB 的行为未验。
- **做法**：帧长集 {1000（40 B 尾拍）/ 1466（58）/ 1538（2）} × 延迟档 {(2,9),(200,200)}，写入-读回逐字节比对 + 监视器 wstrb 期望值自检（末拍 `wstrb == ~(64'hFFFF… >> 尾字节数)`）。
- **验收**：全部组合逐字节一致；上板后在真 MIG 上再复跑一次（场次3 判据 4）。

### A4 = 集成顶层（第一级插桥，1 天含量级）

1. **建工程**：`D:\FPGA\prj\project_10\prj\`（新建，幂等 `scripts/create_project.tcl`，参照 project_9 风格）；part `xcku060-ffva1156-2-i`。
2. **源**：prj9 全部 rtl（栈/泵/pack/unpack/Aurora shared_logic）+ project_10 三层 rtl + **`ddr4_0.xci`（从 project_4 拷入或按同参数重建——拷入前先 `compare_xci` 确认无版本漂移）**。
3. **顶层改动**：`泵A 输出 → frame_mem_if 帧侧进`、`frame_mem_if 帧侧出 → pack 输入`（**只改这两根线**，栈/pump/Aurora 零改动——实施单 §3.1"只增不改"边界）；MIG 侧接 `ddr4_0`；`init_calib_complete` 硬门控已在桥内（W2 T6 验证）。
4. **XDC**：沿用 prj9 XDC + prj4 的 `mig_verify_pins.xdc`（107 脚双源一致在案）；时钟约束以 MIG 生成 XDC 为准不覆盖。
5. **ILA 按域分挂**（铁律：跨域采样曾致 WNS −2.639 ns）：`ui_clk` 域 ILA（Lw/Lr 测量窗口：`arvalid→rvalid` 首拍、`awvalid→bvalid`；槽表写/读指针；`wr_stall/ill_rd/len_err` 计数器）+ `user_clk` 域 ILA（帧计数，沿用差分链风格）。
6. **命令通道（W5 内容）本轮不接**——W3 只做数据面第一级；UDP 命令解析器等 W5，避免一次引入两个变量。

### A5 = scratch 综合 + 实现（判读 B2）

- 流程：`synth_design` 看 CW → `opt/place/route` → **`report_timing_summary` 看 WNS/WHS**（30–60 min/次，MIG 域 38359 端点零余量基线在案）。
- 判读三分支：**≥0** → 产出位流待场次3；**<0 但 >−0.5 ns** → 优化（桥内加一级流水/物理约束）重跑；**仍 <0** → **停下上报**——触发 #14 的 BRAM v2 回退判据（这是路线决策点，不是本单可自决）。

## 四、依赖与顺序（总览）

```text
A1(B1 端口) ──► A5(scratch 时序) ──► A4 位流 ──────────────┐
A2(B3 变延迟模型) ──► A3(B4 尾拍专项)                          │
                                                              ▼
场次1(prj9: W0+E1/E3/E4)   场次2(prj4: W1+Lw/Lr) ──回填──► 场次3(W3 联调 J2/J6)
        │（与轨A完全并行，随时可插）        │
        └── E2 单独排期，不进任何场次 ──────┘
```

- 轨 A 与场次1/2 **完全并行**（互不依赖）；场次3 需 A5 位流 + 场次2 的 Lw/Lr（判读用）。
- **关键路径 = A4+A5（约 1 天）**；场次2 的 J1 是唯一"从未取得"的板上判据，**建议尽早排**（场次2 不依赖轨 A，可先于一切执行）。
