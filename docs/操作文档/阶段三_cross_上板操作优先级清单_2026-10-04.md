## 二、【最高优先】DDR4 内存校准首次上板

### 为什么排第一

这是**唯一一块"做好了但从来没上过板"的东西**。内存相关的后续工作全卡在它上面；而它万一失败，往往需要重新做一版位流（要花时间），所以放在一天的最前面最安全。

### 你要做的

**第 1 步｜烧位流**（一条命令，脚本会自动带上调试探针文件）

```powershell
cd D:\FPGA\prj\project_4
vivado -mode batch -source scripts\program_mig.tcl -notrace
```

看到输出 `PROGRAM_OK` 就是烧进去了；再看到 `调试核数量 = 1`、`ui_clk 在跑` 说明芯片已经在工作。

**第 2 步｜看两盏灯**（这才是最终判据）

| 灯 | 亮 = 什么意思 |
|---|---|
| **T22** | 内存校准完成 |
| **T23** | 写进去的 256 拍数据读回来逐字节一致（零错误）|

**两盏都亮 = 这项过了** ✅ ——拍张照，记下时间。

**第 3 步｜顺手抓一次波形**（用来量读写往返延迟，对后面的内存桥设计很重要）

1. 在 Vivado 里打开 **Hardware Manager**（脚本跑完通常已经开着）
2. 找到调试核 **u_ila**
3. 触发条件设成 **probe_state（状态机当前步骤）等于 1**（= 刚发出写地址那一拍）
4. 采样深度拉到最大，点 **Run trigger**
5. 抓到后：**File → Export → Export ILA Data**，存成 CSV，放到 `毕设\截图归档\`

### 万一没过：对照着看

| 现象 | 含义 | 你做什么 |
|---|---|---|
| **T22 一直不亮** | 校准没完成 | 拍照 + 把 `program_mig.tcl` 的整段输出发我。我会按顺序出两版新位流：先**降速档**，不行再**把突发长度缩到 64 拍以内**（现在这版例程自带的 256 拍突发有跨 4KB 边界的隐患，之前核查时已经发现） |
| **T22 亮、T23 灭** | 校准成功，但读写比对有错 | 把 ILA 里的 **probe_err** 数字发我（那是错误计数），我看是哪一拍出的问题 |
| 两盏都不亮 + 脚本报"时钟停了" | MIG 根本没跑起来 | 先确认烧录时确实带了 `.ltx` 探针文件（脚本已自动带）；再拍照发我 |
| `MISSING_FILE` | 位流文件不在 | 告诉我，我核对文件位置（正常应该都在） |

> **别自己反复重烧**：烧录本身没错时，重烧解决不了校准问题，反而浪费时间。拍照发我最快。

## 三、【次高】光链路基线复测

### 为什么做

15 分钟的体检，证明"板子是活的、光纤是通的、网口是好的"。**在动内存线之前先把物理层排除掉**，后面出问题才好定位。

### 你要做的

**第 1 步｜插好光纤**（笼 A ↔ 笼 B，一根 LC 双工跳线），然后烧位流：

```powershell
cd D:\FPGA\prj\project_9
vivado -mode batch -source scripts\program_board.tcl -notrace
```

脚本会自动烧位流 + 探针，并打印两项体检结果：

- `调试核数量 = 2` → 说明跑的确实是这套设计
- `eth_rxc(PHY 125M): 时钟在跑` → 说明**网口链路已经建立**

**第 2 步｜看板子**：**T23 常亮**（链路指示）

**第 3 步｜电脑侧三项**

```powershell
ping 192.168.1.10 -n 20
```
→ 判据：**0% 丢包、全部 <1ms**

```powershell
$env:PYTHONUTF8 = 1
cd D:\FPGA\prj\project_9
python scripts\udp_verify.py
```
→ 判据：**回显逐字节一致 12/12**

（可选佐证）Wireshark 过滤 `udp.port==1234`，能看到请求/回显成对、内容一样。

### 万一没过

| 现象 | 先查什么 |
|---|---|
| T23 不亮 | 光纤插到底了吗？模块是 **10G** 的吗？跳线两端都拧紧了吗？ |
| 脚本说 eth_rxc 时钟停了 | 网线是否插在 **GE1**；换一根网线试试 |
| ping 不通 | `ipconfig` 看电脑是不是 192.168.1.102；网线灯亮不亮 |
| ping 通但回显 12/12 不过 | 把 udp_verify 的完整输出发我 |
