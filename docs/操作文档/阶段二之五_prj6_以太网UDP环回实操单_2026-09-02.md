## ⚡ 分支决策（2026-09-02 晚，光电转缺失）

> **U2 结果：实验室无 SFP→RJ45 光电转模块。** 载体调整（路线图决策 #8）：**第 45 章网口版先行**——PC 网线直连板载 RJ45 双千兆口（YT8531 PHY，RGMII），**零新增硬件**；第 59 章光口版**顺延**，本卡 §1-§8 光口定版全部保留，光电转/带 SFP 口交换机到位后只换前端即可复用。
> **两版关系**：UDP/ARP/ICMP 协议栈核心完全相同（`eth_udp_loop` 原封不动，第 59 章本就是第 45 章换前端）——网口版先把协议栈跑通，光口版届时只剩"前端转换"的调试量。
> **代价（如实记录）**：网口版不经过 SFP/光纤——SFP 传输验证仍由串口线（Aurora 内环）承担，真实光路证据继续等联调阶段/光电转到位。
> **网口版定版见 §4A**——比光口版更简单：**全 RTL、零 Xilinx 以太网 IP**。

## 1. 数据通路与模块清单

数据流（p1790 + 顶层代码 p1844-1849 逐线核对）：

```
PC(RJ45, 192.168.1.102) ⇄ 千兆光电转(SFP→RJ45) ⇄ 光纤 ⇄ SFPA(X1Y11)
   ⇅ gig_ethernet_pcs_pma_0（光 ↔ GMII，1000BASE-X，自协商，userclk2=125M）
   ⇅ GMII（8bit @ 125MHz）
   ⇅ tri_mode_ethernet_mac_top（GMII ⇄ AXI4-Stream，前导码/补零/CRC 硬件生成）
   ⇅ AXI4-Stream（8bit）
   ⇅ axi_ctrl（AXIS ⇄ GMII，补/剥前导码 7×8'h55 + 8'hD5）
   ⇅ eth_udp_loop（第 45 章原样：收完一包立即回发，目的 MAC/IP = 收到的源地址）
```

| 模块 | 职责 | 来源/复用 |
|------|------|----------|
| clk_wiz_0 | 100M 差分 → 50M 单端（independent_clock_bufg 用） | IP（手册 p1846） |
| gig_ethernet_pcs_pma_0 | 1000BASE-X 光↔GMII、自协商、8b/10b 线码 | Xilinx PG047 IP，配置 §2.1 |
| tri_mode_ethernet_mac_top | GMII ⇄ AXI4-Stream、前导码/<64B 补零/CRC | IP + 包装层，手册 59.4.4 |
| axi_ctrl | AXIS⇄GMII 桥，补/剥前导码+SFD | 手册 59.4.2 全代码 |
| eth_udp_loop | ARP/ICMP/UDP 三协议切换 + UDP 环回 | 第 45 章全套：udp_rx / udp_tx / crc32_d8 / arp / icmp / eth_ctrl / async_fifo_2048x8b（[[笔记和开发指南/以太网UDP测试实验]] §三） |

**为什么网口版→光口版只动前端**：第 45 章顶层删掉 gmii_to_rgmii，GMII 源从 PHY 换成 axi_ctrl——协议解析层零改动（[[笔记和开发指南/以太网UDP测试实验]] §六）。地址定版继承：板卡 `00_11_22_33_44_55 / 192.168.1.10`，PC `192.168.1.102`，收发端口 `1234/1234`。

## 2. IP 配置定版卡

### 2.1 gig_ethernet_pcs_pma_0（1G/2.5G Ethernet PCS/PMA or SGMII，PG047；手册 59.4.6 p1827-1834）

| 配置项 | 定版值 | 为什么 |
|---|---|---|
| 线程选择 | **1G** | 千兆光口（p1828） |
| Select standard | **1000BASE-X** | 光口标准（vs SGMII=板对板串行，p1829） |
| Physical Interface | **GMII** | 内部接 TEMAC（p1830） |
| Transceiver type | GTH | KU060 |
| Reference Clock Frequency | **156.25 MHz** | #4，与 IBERT/Aurora 定版同源（p1831） |
| Transceiver Location | **X1Y11（SFPA）** | 定版继承；⚠️ 手册例程绑的是光口 D=X1Y8（p1850），我们改 SFPA——坑位 C5 |
| DRP Clock Frequency | **50 MHz** | #5；UltraScale 的 independent_clock_bufg 外部输入须与之一致（p1831-1832） |
| RX GMII Clk Src | TXOUTCLK（默认） | 手册选择（p1832） |
| MDIO Management Interface | **不勾** | 静态配置走 configuration_vector/an_adv（顶层实证无 MDIO 端口，p1846-1849） |
| Auto-Negotiation | **勾选** | 1000BASE-X 与对端自协商（p1832） |
| MDIO for external PHY | **不勾** | 无外部 PHY |
| Shared Logic | **in core** | 单 IP 简化（p1833） |

生成后终验（Aurora xci 双证套路）：transceiver 类型 / GT 位置 X1Y11 / refclk 156.25M / AN 使能 / DRP 50M 逐项对 xci。

### 2.2 tri_mode_ethernet_mac（Tri Mode Ethernet MAC，PG051；手册 59.4.3 p1805-1815）

| 配置项 | 定版值 | 为什么 |
|---|---|---|
| Speed | **1Gbps** | p1806 |
| PHY Interface | **Internal** | PCS/PMA 在片内（p1807） |
| MAC Speed | **1000Mbps** | 1000BASE-X 速率固定 1G |
| Internal mode clock source | **User clk2**（默认） | MAC 收发路径由 userclk2 驱动（p1807） |
| Management Type | AXI4-Lite | s_axi_aclk 接 userclk2（见坑位 C1） |
| MDIO / Add IOB for MDIO | **都不勾** | 无外部 PHY，寄存器不用配（p1807） |
| Features：半双工/AVB/帧过滤/PFC/统计计数 | **全不勾** | 全双工最简（p1809） |
| Shared Logic | 界面不可选（默认） | p1808 |

⚠️ **坑位 C1（手册内部矛盾，预裁决）**：p1807 说"AXI4-Lite Frequency 与 user_clk2 相同，选 156.25M"，但 p1841 时钟结构明确 **1G 模式 userclk2=125MHz**（156.25M 是 2.5G 档的 userclk 值）。**裁决：以 125M 为准**——GUI 下拉选与实际接入时钟一致的档位，生成后用时钟报告复核；若与手册截图不符，偏差回填本卡。

## 3. 顶层关键配置（p1846 原文实证）

| 信号/参数 | 定版值 | 语义 |
|---|---|---|
| sfp_tx_disable | 1'b0 | 开光模块发射 |
| sfp_rs0 / sfp_rs1 | 1'b1（手册原样） | ⚠️ 坑位 C2：RS 是 ">4.25G 速率选择"引脚（[[笔记和开发指南/光纤接口眼图]] §4.1）；本实验 1G 若协商不通，**先试拉 0** |
| signal_detect | 1'b1 | 光模块在位恒 1——接 0 会使 RX 同步状态机永久丢失（p1849） |
| configuration_vector[1:0] | 2'h0 | 禁止内部环回 |
| configuration_vector[2] | 1'b0 | 禁止低功耗 |
| configuration_vector[4:3] | 2'b10 | **开启自协商** |
| an_adv_config_vector | 16'h0021 | 自协商广告字（p1849；bit 语义对照手册图 59.4.70 / PG047） |
| an_restart_config | 1'b0 | 不重启 AN |
| tx_ifg_delay / 流控 | 0 | 最小帧间隔、不开流控（p1812） |

📌 **TEMAC 帧长行为（p1814 原文）**：发送 <64B 帧自动补 0 至 64B 并自动加 4B CRC；接收自动剥 CRC 但**不剥补零** → 有效载荷 14~1514B（含 14B MAC 帧头）。回环比对按发送长度核对，别把补零当错误（坑位 C3）。

## 4. 引脚预定版 XDC（SFPA 版，可粘贴）

```tcl

set_property -dict {PACKAGE_PIN H27 IOSTANDARD LVCMOS33} [get_ports sfp_rs1]

```

## 4A. 网口版（第 45 章）定版 —— ⚡ 当前执行分支

### 数据通路（比光口版省掉三个部件）

```
PC(RJ45, 192.168.1.102) ⇄ 网线(CAT-6) ⇄ 板载 GE1 RJ45（YT8531 PHY，RGMII）
   ⇅ gmii_to_rgmii（rgmii_rx: BUFIO+BUFG+IDDRE1 / rgmii_tx: ODDRE1，全 RTL）
   ⇅ GMII（8bit @ 125MHz，单时钟域：gmii_rx_clk = eth_rxc 经 BUFG）
   ⇅ eth_udp_loop（第 45 章原样：arp + icmp + udp + eth_ctrl + async_fifo_2048x8b）
```

无 PCS/PMA、无 TEMAC、无 axi_ctrl——**纯 RTL + 1 个 FIFO IP**，工程量小于光口版。

### YT8531 PHY 要点与坑位

| 编号 | 事实/坑 | 处置 |
|---|---|---|
| C7 | PHY 硬件复位：`eth_rst_n` 低电平须持续 **10ms** | FPGA 输出上电延时释放（看书顶层实现），别上电即拉高 |
| C8 | RXD0_RXDLY / RXD1_TXDLY **上拉** → RX/TX 延时由 PHY strap 承担（RXC 相对 RXD 中心对齐 ~2ns），**FPGA 无需 IDELAY/ODELAY** | 上板前与原理图核对 strap（U8）；若不符再补延迟原语 |
| C9 | 第 42 章 MDIO 实验 XDC 中 `eth_rst_n=AD26/LVCMOS33`，与表 43.5.1 的 `AA33/LVCMOS18` **不一致** | 以 ARP/UDP 章（表 43.5.1）为准；疑为双口之别或章节笔误，原理图终核（U7） |
| C10 | 板载**双**千兆口，表 43.5.1 是 GE1 | 网线插 GE1；若插 GE2 引脚另查 |
| — | PHY 地址由 AD0-2 strap 决定；本实验**不用 MDIO**（PHY 默认配置 + 自协商即可工作） | 无需关心 |
| — | 自协商默认开，仅支持 1000Mbps（例程不支持 10/100M） | PC 网卡千兆口直连 |

## 5. PC 侧硬件与网络准备（你操作）

> ⚡ **网口版（当前分支）只需三样**：① CAT-6 网线一头 PC 网卡、一头板卡 **GE1**；② PC 静态 IP；③ 工具（下 3 条）。下面的光电转（1）与光模块（4）是**光口版顺延项**，网口版用不到。

1. **光电转换硬件**（U2，光口版顺延）：千兆光电转（SFP 转 RJ45）模块（手册图 59.5.1）**或**带 SFP 光口的千兆交换机，实验室有什么用哪个。连接：PC 网线（推荐 CAT-6）→ 光电转 RJ45 → 光电转 SFP 座（插同型光模块）→ 光纤 LC-LC → 板卡 SFPA。
