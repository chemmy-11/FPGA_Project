## 📖 第一步：必读文档（本周完成，按优先级）

### ⭐ 导师指定重点

**1. [[8.3/智能体互联网/2025-ICLR-MoA-翻译]]**（智能体混合架构，ICLR 2025）
- **为什么是重点**：MoA 是最终应用场景的理论原型——多个 Agent 通过 FPGA 交换中间结果、分层迭代优化，正是平台要支撑的"多 Agent 协同推理"
- **读时关注**：
  - 核心概念：**提议者（Proposer）**与**聚合器（Aggregator）**的角色分工
  - 分层架构：每层智能体把上一层输出作为辅助信息，迭代合成最终回复
  - 模型选型两条标准：**性能指标（胜率）+ 多样性考量**（异构模型协作 > 同模型重复）
  - 协作性发现：即使参考模型更弱，模型也能借助他人输出提升质量

**2. [[8.3/任务分工-2026-05-07]]**（FPGA 平台移植路线与分工）
- **为什么是重点**：这就是 FPGA 开发的地图——5 阶段路线 + 双组分工 + 接口契约
- **读时关注**：
  - **5 阶段路线**：①软硬件协同流程（MicroBlaze）→ ②AXI 总线族 → ③DDR4/MIG → ④AXI DMA+中断 → ⑤Aurora/GTH
  - **双组分工**：第一组系统软硬件（阶段 1-4）、第二组高速接口（阶段 5）可并行推进
  - **AXI4-Stream 接口契约**（合并代码的关键）：数据位宽对齐（10G→64-bit）、跨时钟域 FIFO 归属、TVALID/TREADY/TLAST 握手
  - 起步节奏：阶段 1/2/4（软件侧）与阶段 3/5（硬件侧）双线突破
