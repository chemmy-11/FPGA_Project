## 三、过程中的坑（已就地修复，值得记）

1. **bat 中文注释 + cmd GBK 解析 = 莫名"文件名、目录名或卷标语法不正确"**：`pump_stress.bat` 是四个回归 bat 里唯一带中文注释的（其余三个全 ASCII 所以从没炸过）。UTF-8 中文经 cmd 的 GBK 解析在某种字节组合下破坏解析。修法 = prj11 版注释全 ASCII + if/else 括号内 `set` 改 goto 结构（顺带消除变量展开隐患）。**候选坑账本 #35**。
2. Git Bash 里 `python <<'EOF'` 内嵌含 `\\x`、`\\p` 的 bat 文本再次触发转义坑（unicodeescape SyntaxError）——重申纪律：**生成文件内容一律 Write 工具/脚本文件，不在 heredoc 里拼**（与既有坑账本同族）。
